## Running the project

database.m - Database for the project, contains all variables, must be within the same
             folder as the file where the variables want to be unpacked

dbFunc.m - Initialises the database for the Simulink simulations, must be run before the
           Simulink simulations so that the variables can be accessed

leggedRobotSim.m - Contains the code for running the 2D model that solves the dynamics                     of the joints using numerical methods

leggedRobotSim2D.slx - Models the 2D model in Simulink, can run as long as dbFunc.m has
                       been run

SimulinkResults.m - Records the results of the leggedRobotSim2D.slx simulation and plots

modelVerification.m - Both SimulinkResults.m and leggedRobotSim2D.slx must be run before
                      the models can be verified using this code, plots qualitative                           graphs of the results as well as the quantitative metrics (RMSE,                        MAE, correlation coefficient)

leggedRobotSim3DPrimitive.slx - Models the 7 DoF model with a walking gait generated by
                                piecewise functions in Simulink, can run as long as
                                dbFunc.m has been run

leggedRobotSim3D.slx - Models the 7 DoF model with a walking gait generated by a sine                          wave function in Simulink, can run as long as dbFunc.m has been                         run

SimulinkResults3D.m - Contains code to display the results recorded from the 3D Simulink
                      simulations, can display either of the models (i.e. the two                             differing models in terms of how the gait is generated)

parameterSweep.m - Contains code that performs a parameter sweep of the proportional and
                   differential gain values in the PD controllers of the 7 DoF model                       where the gait is generated through piecewise functions

parameterSweepDims.m - Contains code that performs a parameter sweep of the link length
                       ratios of the 7 DoF model where the gait is generated through
                       piecewise functions
